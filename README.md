# 👜 RV Leather Bags Website

A modern, responsive leather bags website created for **RV Leather Bags**.  
The website showcases leather products with a clean layout, product images, company information, and contact details.

## 🌐 Live Website

[Visit the Live Website](https://leather-website-omega.vercel.app)

## ✨ Features

- 🏠 Home section with a visual hero area
- 👜 Leather bag product showcase
- ℹ️ About section
- ⭐ Why Us section
- 📞 Contact section
- 📱 Responsive design
- 🖼️ Product and banner images
- 🎨 Clean and simple user interface

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling and responsive design
- **JavaScript** — Interactive functionality
- **Vercel** — Deployment

## 📁 Project Structure

```text
leather-website/

```

## 🚀 How to Run Locally

1. Clone this repository:

```bash
git clone https://github.com/sainadhkarra8-beep/stachel-studio.git
```

2. Open the project folder.
3. Open `index.html` in your browser.

No additional installation or dependencies are required.
